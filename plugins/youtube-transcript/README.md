# youtube-transcript

YouTube動画のリンクから字幕(文字起こし/スクリプト)を取得し、**要約＋詳細解説＋整形済み全文**を1つのMarkdownファイルに書き出す Claude Code 用スキル。

## 仕組み

1. **メタ・字幕取得** — `yt-dlp`(uvx経由)で動画メタ情報と字幕を取得
2. **言語優先** — 日本語字幕(手動/自動/翻訳)を優先し、無ければ原語(英語等)にフォールバック
3. **整形** — VTTの重複(ローリングキャプション)を除去してプレーンなトランスクリプトに整形
4. **生成** — 要約(TL;DR)＋詳細解説＋全文トランスクリプトを組み立て
5. **書き出し** — 動画タイトルから安全なファイル名を生成してMarkdownを保存

要約・解説は日本語で記述（トランスクリプト本文は字幕の原語のまま掲載）。

## 前提

- `uv` / `uvx` が利用可能（`yt-dlp` は `uvx` が都度取得）
- ネットワーク接続

### 供給網ハードニング

`yt-dlp` は**バージョンを固定**して実行する（`uvx yt-dlp@<固定版>`）。未固定だとPyPIの最新版へ浮動し、悪性リリースをレビュー猶予なく実行してしまうリスク（サプライチェーン攻撃）があるため。

- 固定バージョンはスクリプトの `YTDLP_VERSION` で管理
- 更新は `uvx yt-dlp@latest --version` で最新を確認し、動作検証のうえ意図的に引き上げる
- 一時的な上書きは環境変数 `YTDLP_VERSION=... ` で可能

## 使い方

```
/youtube-transcript <YouTube URL> [出力先パス]
```

- URLを省略した場合は問い合わせる
- 出力先を省略した場合は保存先(llm-wiki/inbox・カレント・任意パス)を問い合わせる
- 出力先はディレクトリ(その直下に自動命名)でも、`.md`ファイルパス指定でも可

例:

```
/youtube-transcript https://youtu.be/XXXXXXXX
/youtube-transcript https://youtu.be/XXXXXXXX ./notes
```

## 出力内容

- 動画メタ情報(タイトル/投稿者/尺/公開日/字幕言語/取得日)
- TL;DR(要約)
- 詳細解説(章立て)
- 全文トランスクリプト(整形済み)

## 注意

- 自動字幕の場合は聞き起こし誤りを含む可能性があるため、重要箇所は原典で確認すること
- 字幕が存在しない動画は文字起こし不可(音声認識は範囲外)
